
# 🧬 RNA-Seq Analysis Educational Project

## 📋 Overview

This educational group project focuses on analyzing RNA sequencing data from single cells. Our team is dedicated to mastering cutting-edge tools and methods for processing, analyzing, and interpreting single-cell RNA-seq datasets.

## 🚀 Getting Started

### Prerequisites

* R (version 4.0+ recommended)
* Basic understanding of molecular biology concepts

### Installation

```r
# Clone the repository
git clone https://github.com/gnumic/T4_25_gnomic.git

# Navigate to project directory
cd gnomic

# Install dependencies
install.packages("renv")
renv::restore()
# Or use the traditional method
# install -r requirements.txt
```

## 📁 Project Structure

* `data/` - Raw and processed RNA-seq datasets
* `scripts/` - R scripts for data processing, normalization, and analysis
* `results/` - Output files, visualizations, and analysis results
* `docs/` - Documentation, protocols, and final reports

## 👥 Team

Our interdisciplinary team includes bioinformaticians and molecular biologists collaborating under expert mentorship to develop skills in:

- Single-cell RNA-seq analysis
- Differential expression analysis
- Pathway enrichment
- Cell clustering and annotation
